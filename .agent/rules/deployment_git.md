# Reglas de Despliegue y Git

- **Rama Activa**: `develop`.
- **Despliegue Local**: Eliminado. Todas las pruebas se realizan directamente en **Vercel** en la rama `develop`.
- **Restricción de Commits y Push**: No realizar `git commit` ni `git push` a menos que sea ordenado explícitamente por el usuario.
