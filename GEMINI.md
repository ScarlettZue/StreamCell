# Reglas y Memoria del Proyecto - StreamCell

## Directivas de Entorno y Git (Estrictas)

1. **Rama de Trabajo**:
   - Permanecer siempre en la rama `develop`.

2. **Despliegue y Entorno de Pruebas**:
   - **NO ejecutar ni mantener despliegues o servidores locales** (Vite, Express, etc.).
   - Las pruebas se realizan de ahora en adelante directamente en **Vercel** desplegado desde la rama `develop`.

3. **Políticas de Git (Commits y Push)**:
   - **NO realizar `git commit` ni `git push`** de forma autónoma.
   - Solo se realizarán commits y push cuando el usuario lo ordene explícitamente.
